## Convenções desta KB

- **Implementado**: comportamento presente no código atual.
- **Parcial**: interface ou estrutura existe, mas não conclui o fluxo de negócio.
- **Planejado**: previsto no produto, porém não disponível para uso.
- Exemplos usam pt-BR e BRL, pois essa é a experiência atualmente codificada.
